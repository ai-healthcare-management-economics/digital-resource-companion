# Stage 9: Reassess continuing value, affordability, and support

Reassess the current comparator, realized benefits, lifecycle costs, budget exposure, supplier support, infrastructure dependencies, continuity, residual value, and credible replacement or exit options.

**Primary chapters:** 6, 9, 12

**Primary resources:** AIHE-B02; AIHE-B03; AIHE-B04; AIHE-D01; AIHE-D05

**Supporting resources:** AIHE-CASE06; AIHE-CASE06B; AIHE-CASE09B; AIHE-CASE12; AIHE-PY10; AIHE-PY11; AIHE-PY17

**Recommended preceding records:** AIHE-A01; AIHE-B01; AIHE-D01; AIHE-D03

**Typical output:** Updated financial case, supportability and continuity assessment, current alternatives, and a justified renewal, renegotiation, restriction, replacement, or retirement recommendation.

**Decision gate:** Does continuing use remain justified, affordable, supportable, and preferable to current alternatives without compromising mandatory safeguards?
