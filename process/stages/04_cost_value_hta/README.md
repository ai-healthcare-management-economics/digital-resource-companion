# Stage 4: Model cost, value, affordability, and HTA

Estimate lifecycle cost, pricing exposure, benefit realization, cost-effectiveness, budget impact, affordability, distribution, reimbursement, and HTA implications.

**Primary chapters:** 6; 7

**Recommended preceding records:** AIHE-A01; AIHE-A03; AIHE-A04

**Primary resources:** AIHE-B01; AIHE-B02; AIHE-B03; AIHE-B04

**Supporting resources:** AIHE-CASE06; AIHE-CASE07; AIHE-B; AIHE-M

**Typical output:** Economic specification, lifecycle cost model, benefit-realization register, affordability profile, and conditional economic recommendation.

**Decision gate:** Does the intervention have a defensible value proposition and a financeable path under realistic scenarios?

This stage is part of the Master Institutional Decision Lifecycle and should be adapted to the specific jurisdiction, institution, population, system version, evidence cut-off, and accountable authority.
