# Stage 3: Establish evidence and quality requirements

Define validation, reporting, appraisal, quality-control, accreditation, patient-safety, and independent-assurance requirements before consequential use.

**Primary chapters:** 5; 11

**Recommended preceding records:** AIHE-A01; AIHE-A03; AIHE-A04

**Primary resources:** AIHE-C01; AIHE-C02; AIHE-EX05; AIHE-RG02; AIHE-RG06

**Supporting resources:** AIHE-CASE05; AIHE-CASE11; AIHE-V

**Typical output:** Evidence plan, local-validation specification, monitoring indicators, acceptance thresholds, and corrective-action route.

**Decision gate:** Is the planned evidence proportionate to intended use, uncertainty, and consequence?

This stage is part of the Master Institutional Decision Lifecycle and should be adapted to the specific jurisdiction, institution, population, system version, evidence cut-off, and accountable authority.
