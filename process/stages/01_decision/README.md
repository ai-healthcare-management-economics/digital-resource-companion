# Stage 1: Define the decision

Specify the service problem, population, complete intervention, realistic comparators, outcomes, value mechanism, stakeholders, and accountable authority.

**Primary chapters:** 1

**Recommended preceding records:** None — this stage initiates the decision.

**Primary resources:** AIHE-A01; AIHE-A02

**Supporting resources:** AIHE-RG07; AIHE-CASE01

**Typical output:** Approved decision and use-case specification with decision rights and an evidence plan.

**Decision gate:** Is the problem sufficiently important and specified to justify further assessment?

This stage is part of the Master Institutional Decision Lifecycle and should be adapted to the specific jurisdiction, institution, population, system version, evidence cut-off, and accountable authority.
