# Self-study guide

## Suggested sequence

1. Read the scn without opening the worked solution.
2. Identify the decision-maker, comparator, value mechanism, and mandatory safeguards.
3. Complete the spreadsheet using the default assumptions.
4. Change at least two decision-critical assumptions.
5. Compare the result with `solution/WORKED_SOLUTION.md`.
6. Record which evidence would be required before a real decision.

## Suggested time

45-75 minutes for individual study or 60-90 minutes for a group review.
