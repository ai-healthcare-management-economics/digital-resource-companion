# Self-Study Guide

## Suggested sequence

1. Allow 20 minutes for independent reading and problem framing.
2. Ask participants to classify each supplied indicator as observed, forecast, process, outcome, or balancing information.
3. Use the wb to identify intervals in which the forecast was adequate but action was too late.
4. Require each group to identify one likely bottleneck shift and one data-governance weakness.
5. Ask for a decision recommendation that includes conditions, owners, evidence requirements, a review date, and stopping rules.
6. Compare recommendations with the worked solution; emphasize that more than one defensible answer is possible when assumptions are explicit.

## Discussion prompts

- Does the proposed command centre create reusable organizational capability or a permanent new coordination cost?
- Which variables are actionable within the decision window?
- How should forecasts be displayed so they are not mistaken for observed facts?
- What evidence would justify attributing improved flow to the dashboard?
- When should a dashboard recommendation be ignored or overridden?
