# Worked examples

This folder is the single canonical location for the Digital Resource Companion worked examples. The `00_case_method/` folder provides a common method for analysing a case. The remaining folders contain the chapter-aligned synthetic cases referenced by the book and the web companion.

Each worked example normally includes:

- a decision scenario;
- synthetic input data in CSV and JSON formats;
- an editable Excel wb and LibreOffice Calc equivalent;
- a worked interpretation;
- a self-study and review guide;
- related-resource mapping; and
- metadata identifying the aligned chapter, version, and resource relationships.

Begin with the scn and develop an independent recommendation before consulting the worked interpretation. Use the browser demonstrations for exploration and the canonical files in this folder for governed adaptation or analysis.

All examples are fictional and synthetic unless explicitly stated otherwise. They are not empirical findings and should not be reused as institutional evidence without independent validation and appropriate local governance.
