## Decision question

How does the preferred option change when conventional economic value is considered with environmental effects, residual value, resilience, equity, and rebound?

## Scenario

A fictional diagnostic network compares edge deployment, commercial cloud hosting, and a shared regional platform. The options provide similar clinical benefit but differ in capital cost, annual fees, energy, water, carbon, residual value, latency, and dependency.

## Objectives

- Define a common functional unit and system boundary.
- Keep conventional and circularity-adjusted results transparent.
- Avoid double counting and arbitrary monetization.
- Test sensitivity to carbon, water, residual value, and resilience.
