# Worked solution: AI-Assisted Remote Diagnostic Pathway: Circularity-Adjusted Economic Evaluation

## Interpretation

Cloud has the lowest initial cost but the highest five-year operating cost and water burden. Edge has the strongest latency and residual value but requires more capital and local maintenance. The shared regional platform has the strongest overall balance in the synthetic example, conditional on data governance, interoperability, and exit rights. Conventional net benefit should be reported first, followed by disaggregated circular and environmental evidence.

## Decision record

A complete institutional record should document the comparator, assumptions, evidence cut-off, accountable owner, uncertainty, mandatory safeguards, monitoring thresholds, review date, and exit or renewal criteria.
