# AIHE-D01 — Vendor Evidence and Contract Requirements

**Primary chapter:** Chapter 9: Problem-First Procurement and Vendor Governance  
**Release:** V1.0  
**Status:** Current consolidated resource

## Purpose

Translate evidence, interoperability, data, security, monitoring, update, service, remedy, portability, and exit requirements into contract terms.

## Included files

- `data/AIHE-D01_blank.csv` and `.json`: machine-readable blank record
- `data/AIHE-D01_example.csv` and `.json`: synthetic worked example
- `data/AIHE-D01.schema.json`: validation schema
- `edit/docx/AIHE-D01_template_and_worked_example.docx`: editable narrative record
- `edit/xlsx/AIHE-D01_workbook.xlsx`: editable workbook
- `flow/`: process explanation, source, and rendered diagrams

## Use

Begin with the institutional decision rather than the form. Preserve the resource identifier, V1.0, evidence cut-off, intervention version, accountable owner, review date, conditions, unresolved uncertainty, and local modifications. Worked examples are synthetic unless a documented source states otherwise.

This author-developed resource supports structured analysis and documentation. It does not establish safety, effectiveness, compliance, cost-effectiveness, affordability, or institutional authorization.
