# Chapter 1: AI as a Health-System Intervention

Chapter-level decision process aligned to the fifteen-chapter reference edition.

## Process steps

### 1. Define the institutional problem
State the baseline burden, affected population, decision-maker, and decision window.

### 2. Map the complete intervention bundle
Include data, model, interfaces, users, review, workflow, downstream action, monitoring, support, and exit.

### 3. Identify realistic comparators
Compare AI with current practice, process redesign, staffing, conventional digital tools, other AI, and no-change options.

### 4. Formulate the causal value hypothesis
Explain how the intervention changes decisions, actions, outcomes, resources, equity, and public value.

### 5. Specify evidence and safeguards
Define the evidence required, mandatory safeguards, uncertainty, and conditions for responsible use.

### 6. Set a reversible decision rule
Define proceed, redesign, validate silently, pilot, scale, restrict, pause, replace, or retire criteria.

## Illustrative application

A health-system board compares an AI triage system with additional triage staff, process redesign, and point-of-care testing.

## Status and limitations

This process flow is a navigational and decision-support aid. It is not a validated clinical, regulatory, legal, procurement, cybersecurity, accreditation, or HTA instrument. Adapt it to the relevant jurisdiction, institution, population, workflow, technology version, evidence cut-off, and accountable authority.
