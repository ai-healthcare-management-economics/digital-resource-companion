# Chapter 8: Decision Modelling, Simulation, and the Value of Information

Chapter-level decision process aligned to the fifteen-chapter reference edition.

## Process steps

### 1. Translate the decision into a model specification
Define the causal structure, states or events, time horizon, perspective, outputs, and decision rule.

### 2. Select the analytic or simulation method
Match decision tree, Markov, microsimulation, discrete-event, system-dynamics, agent-based, or hybrid methods to the problem.

### 3. Assemble data, parameters, and evidence
Document sources, distributions, correlations, assumptions, heterogeneity, and versions.

### 4. Implement and verify
Test logic, calculations, traces, extreme values, convergence, and code or spreadsheet integrity.

### 5. Validate for the intended use
Assess face, internal, external, predictive, and decision validity proportionately.

### 6. Characterize uncertainty and value of information
Test parameter, structural, methodological, and scenario uncertainty and identify valuable additional evidence.

### 7. Communicate and archive
Present disaggregated results, decision uncertainty, limitations, reproducibility, and versioned records.

## Illustrative application

An imaging-prioritization pathway is modeled using discrete-event simulation and probabilistic sensitivity analysis to estimate queue and uncertainty effects.
