# AIHE-B05 — Model Selection, Uncertainty, and Reproducibility

**Primary chapter:** Chapter 8: Decision Modelling, Simulation, and the Value of Information  
**Release:** V1.0  
**Status:** Current consolidated resource

## Purpose

Select a decision model from the problem structure and document evidence, verification, uncertainty, and reproducibility.

## Included files

- `data/AIHE-B05_blank.csv` and `.json`: machine-readable blank record
- `data/AIHE-B05_example.csv` and `.json`: synthetic worked example
- `data/AIHE-B05.schema.json`: validation schema
- `edit/docx/AIHE-B05_template_and_worked_example.docx`: editable narrative record
- `edit/xlsx/AIHE-B05_workbook.xlsx`: editable workbook
- `flow/`: process explanation, source, and rendered diagrams

## Use

Begin with the institutional decision rather than the form. Preserve the resource identifier, V1.0, evidence cut-off, intervention version, accountable owner, review date, conditions, unresolved uncertainty, and local modifications. Worked examples are synthetic unless a documented source states otherwise.

This author-developed resource supports structured analysis and documentation. It does not establish safety, effectiveness, compliance, cost-effectiveness, affordability, or institutional authorization.
