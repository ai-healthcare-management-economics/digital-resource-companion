# AIHE-C05 — Public Transparency and Communication Record

**Primary chapter:** Chapter 10: Governance, Accountability, and Institutional Risk  
**Release:** V1.0  
**Status:** Current consolidated resource

## Purpose

Define accurate, accessible communication about intended use, limitations, oversight, data, complaints, incidents, and alternatives.

## Included files

- `data/AIHE-C05_blank.csv` and `.json`: machine-readable blank record
- `data/AIHE-C05_example.csv` and `.json`: synthetic worked example
- `data/AIHE-C05.schema.json`: validation schema
- `edit/docx/AIHE-C05_template_and_worked_example.docx`: editable narrative record
- `edit/xlsx/AIHE-C05_workbook.xlsx`: editable workbook
- `flow/`: process explanation, source, and rendered diagrams

## Use

Begin with the institutional decision rather than the form. Preserve the resource identifier, V1.0, evidence cut-off, intervention version, accountable owner, review date, conditions, unresolved uncertainty, and local modifications. Worked examples are synthetic unless a documented source states otherwise.

This author-developed resource supports structured analysis and documentation. It does not establish safety, effectiveness, compliance, cost-effectiveness, affordability, or institutional authorization.
