# Notebook route — AIHE-PY08

Open `08_subgroup_equity_audit.ipynb` in JupyterLab, VS Code, or Google Colab. The notebook calls the same implementation used by the standard Python script.

## Local use

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r ../environment/requirements.txt
jupyter lab
```

Open the notebook, run the synthetic example, and inspect `../outputs/generated/`.

## Google Colab

Clone the complete repository or upload the application folder so that `src/`, `data/`, and `notebook/` remain together. Do not upload identifiable or confidential institutional data to a public notebook service.
