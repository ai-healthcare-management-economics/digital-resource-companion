# AIHE-C02 — Corrective and Preventive Action Record

**Primary chapter:** Chapter 5: Quality Management, Accreditation, and Organizational Learning  
**Release:** V1.0  
**Status:** Current consolidated resource

## Purpose

Document nonconformity, containment, causal analysis, corrective and preventive action, effectiveness, residual risk, and closure.

## Included files

- `data/AIHE-C02_blank.csv` and `.json`: machine-readable blank record
- `data/AIHE-C02_example.csv` and `.json`: synthetic worked example
- `data/AIHE-C02.schema.json`: validation schema
- `edit/docx/AIHE-C02_template_and_worked_example.docx`: editable narrative record
- `edit/xlsx/AIHE-C02_workbook.xlsx`: editable workbook
- `flow/`: process explanation, source, and rendered diagrams

## Use

Begin with the institutional decision rather than the form. Preserve the resource identifier, V1.0, evidence cut-off, intervention version, accountable owner, review date, conditions, unresolved uncertainty, and local modifications. Worked examples are synthetic unless a documented source states otherwise.

This author-developed resource supports structured analysis and documentation. It does not establish safety, effectiveness, compliance, cost-effectiveness, affordability, or institutional authorization.
