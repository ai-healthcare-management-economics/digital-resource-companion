# Data files

- `22_system_dynamics_adoption_capacity_sample.xlsx` is a fully synthetic worked example and is the default input.
- `22_system_dynamics_adoption_capacity_template.xlsx` is a blank input wb with the required worksheets and fields.

Copy the blank template before entering institutional data. Do not place identifiable patient data,
credentials, private keys, or confidential contracts in a public or uncontrolled copy.
