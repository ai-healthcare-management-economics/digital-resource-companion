# AIHE-RG03 — Implementation Framework Selection Guide

**Primary chapter:** 4 — Productivity, Work Redesign, and Implementation 
**Additional chapter alignment:** 4, 11, 12 
**Version:** V1.0

## Purpose

Select CFIR, NASSS-CAT, RE-AIM/PRISM, TAM/UTAUT, and mixed-method approaches according to the implementation question rather than name recognition.

Use the narrative document for interpretation and the spreadsheet for a controlled, updateable record. Verify the current status and edition of external instruments before institutional use.
