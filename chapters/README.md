## Analytical resources

The 36 Python modules cover data quality, validation, calibration, decision utility, costing, financial recognition, economic evaluation, uncertainty, simulation, causal evaluation, forecasting, optimization, monitoring, and decision provenance. Select the method from the decision problem. Begin with the module README, use its declared environment and synthetic inputs, and preserve code, inputs, assumptions, and outputs. Check local data fitness and analytical limitations before institutional reliance.
