## Source policy

Chapter folders are part of the Canonical Source. Generated copies in `docs/`, `bundles/`, `publications/`, and release archives should be regenerated from these canonical resources rather than edited independently.

Stable identifiers should be used in preference to printed page numbers. See [`SOURCE_OF_TRUTH.md`](../SOURCE_OF_TRUTH.md) for the governing maintenance policy.
