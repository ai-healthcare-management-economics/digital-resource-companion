# AIHE-RG01 — Framework Status and Selection Guide

**Primary chapter:** 12 — Decision Architecture and Lifecycle Governance 
**Additional chapter alignment:** 2, 4, 5, 7, 9-12 
**Version:** V1.0

## Purpose

Distinguish legal instruments, standards, guidance, reporting guidelines, appraisal tools, implementation frameworks, and author-developed decision aids; select them according to function and authority.

Use the narrative document for interpretation and the spreadsheet for a controlled, updateable record. Verify the current status and edition of external instruments before institutional use.
