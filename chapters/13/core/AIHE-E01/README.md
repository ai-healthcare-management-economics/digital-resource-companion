# AIHE-E01 — Circular-Economy and Sustainable-AI Assessment

**Primary chapter:** Chapter 13: Circular Health Systems and Resource Stewardship  
**Release:** V1.0  
**Status:** Current consolidated resource

## Purpose

Apply the circularity hierarchy from prevention and reduction through sharing, maintenance, reuse, refurbishment, recovery, and disposal.

## Included files

- `data/AIHE-E01_blank.csv` and `.json`: machine-readable blank record
- `data/AIHE-E01_example.csv` and `.json`: synthetic worked example
- `data/AIHE-E01.schema.json`: validation schema
- `edit/docx/AIHE-E01_template_and_worked_example.docx`: editable narrative record
- `edit/xlsx/AIHE-E01_workbook.xlsx`: editable workbook
- `flow/`: process explanation, source, and rendered diagrams

## Use

Begin with the institutional decision rather than the form. Preserve the resource identifier, V1.0, evidence cut-off, intervention version, accountable owner, review date, conditions, unresolved uncertainty, and local modifications. Worked examples are synthetic unless a documented source states otherwise.

This author-developed resource supports structured analysis and documentation. It does not establish safety, effectiveness, compliance, cost-effectiveness, affordability, or institutional authorization.
