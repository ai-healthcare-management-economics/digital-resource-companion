# AIHE-PY36 - Circular Stock-Flow, Value-Retention, and Leakage Accounting

**Primary chapter:** 13 - Circular Health Systems and Resource Stewardship  
**Version:** V1.0  
**Related resources:** AIHE-E01; AIHE-E05; AIHE-CASE13; AIHE-CASE13B

## Purpose

Quantify resource stocks and flows, inner and outer value-retention pathways, recovery, leakage, resource intensity, and absolute demand for AI-enabled health services.

## Contents

- `python/36_circular_stock_flow_value_retention_and_leakage_accounting.py` - runnable Python analysis;
- `notebook/36_circular_stock_flow_value_retention_and_leakage_accounting.ipynb` - guided Jupyter entry point;
- `data/36_synthetic_stock_flows.csv` - synthetic demonstration input;
- `outputs/example/` - reproducible outputs from the synthetic input; and
- `environment/` - minimal environment information.

## Run

From the module folder:

```bash
python python/36_circular_stock_flow_value_retention_and_leakage_accounting.py --output-dir outputs/generated
```
