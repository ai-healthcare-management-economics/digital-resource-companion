# AIHE-PY39 - Rebound, Induced Demand, and Burden-Transfer Analysis

**Primary chapter:** 13 - Circular Health Systems and Resource Stewardship  
**Version:** V1.0  
**Related resources:** AIHE-E01; AIHE-E04; AIHE-E05; AIHE-CASE13B; AIHE-CASE15

## Purpose

Assess whether lower resource intensity reduces absolute demand and whether costs, environmental effects, material burdens, or labour consequences are shifted across places, populations, suppliers, or periods.

## Contents

- `python/39_rebound_and_burden_transfer.py` - runnable Python analysis;
- `notebook/39_rebound_and_burden_transfer.ipynb` - guided Jupyter entry point;
- `data/39_synthetic_rebound_scenarios.csv` - synthetic demonstration input;
- `outputs/example/` - reproducible outputs from the synthetic input; and
- `environment/` - minimal environment information.

## Run

From the module folder:

```bash
python python/39_rebound_and_burden_transfer.py --output-dir outputs/generated
```
