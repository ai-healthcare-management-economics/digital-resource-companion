# AIHE-RG06 — Diagnostic and Predictive Evidence Appraisal Checklist

**Primary chapter:** 11 — Evidence, Validation, and Real-World Evaluation 
**Additional chapter alignment:** 3, 7, 8, 11 
**Version:** V1.0

## Purpose

Appraise reference standards, index tests, data partitions, calibration, diagnostic accuracy, bias, subgroup performance, clinical utility, and downstream resource consequences.

Use the narrative document for interpretation and the spreadsheet for a controlled, updateable record. Verify the current status and edition of external instruments before institutional use.
