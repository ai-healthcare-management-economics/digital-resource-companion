# Data files

- `04_predictive_model_comparison_sample.xlsx` is a fully synthetic worked example and is the default input.
- `04_predictive_model_comparison_template.xlsx` is a blank input wb with the required worksheets and fields.

Copy the blank template before entering institutional data. Do not place identifiable patient data,
credentials, private keys, or confidential contracts in a public or uncontrolled copy.
