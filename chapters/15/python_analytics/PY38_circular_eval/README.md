# AIHE-PY38 - Circularity-Adjusted Evaluation of an AI-Assisted Remote Diagnostic Pathway

**Primary chapter:** 15 - Circularity-Adjusted Economic Evaluation and Sustainable Value  
**Version:** V1.0  
**Related resources:** AIHE-E04; AIHE-E05; AIHE-CASE15

## Purpose

Compare functionally equivalent remote-diagnostic pathways using conventional economic evidence, physical consequences, selected monetary values, residual value, resilience, equity safeguards, double-counting controls, rebound, and burden transfer.

## Contents

- `python/38_remote_diagnostic_circularity_evaluation.py` - runnable Python analysis;
- `notebook/38_remote_diagnostic_circularity_evaluation.ipynb` - guided Jupyter entry point;
- `data/38_synthetic_remote_diagnostic_pathways.csv` - synthetic demonstration input;
- `outputs/example/` - reproducible outputs from the synthetic input; and
- `environment/` - minimal environment information.

## Run

From the module folder:

```bash
python python/38_remote_diagnostic_circularity_evaluation.py --output-dir outputs/generated
```
