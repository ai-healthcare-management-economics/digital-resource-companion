# Workbook Guide

The Digital Resource Companion provides editable Microsoft Excel (`.xlsx`) and LibreOffice Calc (`.ods`) workbooks for institutional records, worked cases, and Python Analytics inputs. The spreadsheets are designed to support transparent completion and calculation; they are not validated clinical, legal, regulatory, procurement, accreditation, cybersecurity, financial, or health technology assessment instruments.

## Select the right wb

1. Begin with the institutional decision, realistic comparator, population, setting, and accountable owner.
2. Use the chapter pages, decision-stage navigator, or master catalog to locate the smallest sufficient resource set.
3. Use a core wb for a recurring institutional record, a worked-case wb for applied learning, and a Python Analytics wb when a reproducible quantitative method is required.
4. Check the stable resource ID, version, release date, aligned chapter, and canonical folder before reusing an older copy.

## Create a controlled working copy

- Preserve the original release file unchanged.
- Save the institutional copy in approved storage with a local project identifier and version.
- Record the evidence cut-off, system and software version, data period, accountable owner, modification date, and review date.
- Mark locally added sheets, formulas, assumptions, and value judgements clearly.
- Do not enter identifiable patient information, credentials, private keys, confidential contracts, or uncontrolled institutional data.

## Microsoft Excel desktop and Excel Online

Excel desktop provides the most complete support for validation rules, formulas, named ranges, wb protection, and larger datasets. Before sharing through OneDrive or SharePoint, confirm permissions, version history, retention, and download controls. Excel Online is suitable for collaborative completion, but complex formatting, external connections, macros, and some validation behaviour should be checked in the desktop application before consequential use.

## LibreOffice Calc

The `.ods` files are the maintained LibreOffice editions. When opening an `.xlsx` file in Calc or exporting an `.ods` file to Excel format, confirm formulas, data validation, date and number formats, merged cells, wrapped text, and print areas. Retain the original source format and document any conversion-related change.

## Google Sheets

Google Sheets may be useful for low-risk collaborative exercises, but import can alter validation, formatting, named ranges, formulas, and protected areas. Upload only when the data and organizational policy permit it. After import, compare a sample of formulas and outputs with the canonical wb and record the conversion in the project log.

## Quality checks before a wb informs a decision

- confirm that units, currency, price year, perspective, horizon, and comparator are explicit;
- distinguish observations, external evidence, assumptions, modelled estimates, and value judgements;
- check formulas against a hand calculation or independent implementation where proportionate;
- examine missing data, extreme values, scn assumptions, uncertainty, and subgroup effects;
- ensure mandatory safeguards are not averaged away by a favourable score;
- preserve a static export of the exact wb state that informed the decision; and
- record approval conditions, monitoring thresholds, trigger events, next review, and exit criteria.

## Consolidated wb

`bundles/workbooks/AIHE_Core_WB_V1.0.xlsx` and the corresponding `.ods` edition collect all 24 canonical core resources into one file. They are convenience editions for workshops, committees, and offline use. The individual resource folder remains the controlling source when a resource has been updated after the bundle release.
