AIHE-A03 — Institutional Readiness Assessment

Assess strategic, data, infrastructure, workflow, workforce, quality, economic, governance, procurement, and continuing support readiness.

Assess each domain separately as Ready, Remediation required, Uncertain, or Not applicable, supported by evidence and a named owner. Do not infer overall readiness from an average or allow a favourable finding to offset a mandatory safeguard.

Legacy alias(es): AIHE-A; AIHE-L

Browser drafting aid. Static cells preserve the current companion specification; blank cells are editable. This browser form is intended for orientation, scenario drafting, and local working copies.
