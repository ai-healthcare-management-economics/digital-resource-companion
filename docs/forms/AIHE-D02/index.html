AIHE-D02 — Lifecycle Decision State, Staged Evidence, and AI-HED Status

Record the current institutional decision state, exact intervention identity, scope, evidence, conditions, safeguards, triggers, authority, history, and next review.

Use the institutional decision states in Table 12.3. A permission state describes what the institution presently permits; silent evaluation, a pilot, and implementation milestones do not themselves constitute authorization. Link every transition to evidence, accountable authority, scope, conditions, and date.

Legacy alias(es): AIHE-R; AIHE-EX14; AIHE-EX10; AIHE-AE; AIHE-E; AIHE-EX02; AIHE-H; AIHE-K; AIHE-P; AIHE-V

Browser drafting aid. Static cells preserve the current companion specification; blank cells are editable. This browser form is intended for orientation, scenario drafting, and local working copies. Do not enter identifiable patient information or confidential institutional data into a public browser page.
