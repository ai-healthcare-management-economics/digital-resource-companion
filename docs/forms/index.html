Browser-editable core and reference resources

These 31 browser forms expose the canonical 24 core institutional records and seven cross-cutting reference guides. Static cells preserve definitions and guidance; blank cells can be edited locally and exported as JSON or CSV.

Use the browser as a drafting layer, not the final record. Operational decisions should be transferred to a governed local copy with version control, approved evidence, accountable ownership, monitoring conditions, and appropriate data protection.
