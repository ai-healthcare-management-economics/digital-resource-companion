# Data files

- `33_patient_segmentation_clustering_sample.xlsx` is a fully synthetic worked example and is the default input.
- `33_patient_segmentation_clustering_template.xlsx` is a blank input wb with the required worksheets and fields.

Copy the blank template before entering institutional data. Do not place identifiable patient data,
credentials, private keys, or confidential contracts in a public or uncontrolled copy.
