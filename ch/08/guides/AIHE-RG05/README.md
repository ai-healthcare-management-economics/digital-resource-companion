# AIHE-RG05 — Scenario Planning and Real-Options Worksheet

**Primary chapter:** 8 — Decision Modelling, Simulation, and the Value of Information 
**Additional chapter alignment:** 1, 6-9, 12, 15 
**Version:** V1.0

## Purpose

Examine uncertainty through alternative futures, thresholds, staged commitments, learning options, contract flexibility, and explicit exit criteria.

Use the narrative document for interpretation and the spreadsheet for a controlled, updateable record. Verify the current status and edition of external instruments before institutional use.
