## Decision question

Under what conditions, if any, should the hospital scale a command dashboard as a permanent patient-flow management intervention?

## Application objectives

- distinguish observations, forecasts, recommendations, process measures, outcomes, and balancing indicators
- assess forecast error together with action latency and response capacity
- identify bottleneck shifting across beds, imaging, transport, staffing, and discharge
- define data provenance, ownership, escalation, and review requirements
- connect dashboard use to causal evaluation, lifecycle cost, and benefit realization
- produce a conditional recommendation with monitoring and stopping rules.
