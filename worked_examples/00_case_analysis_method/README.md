# AIHE-CASE00 — Common Case-Analysis Method

**Version:** V1.0 
**Alignment:** All fifteen ch 
**Purpose:** Provide a consistent problem-first, evidence-based, economic, governance, and lifecycle method for analysing worked and local cases.

Use the Markdown guide for orientation, the Word or Writer template for a narrative decision record, and the Excel or Calc wb for a structured comparison. The method is deliberately non-compensatory: a mandatory safety, rights, privacy, cybersecurity, equity, continuity, or accountability failure cannot be offset by a favorable score elsewhere.
