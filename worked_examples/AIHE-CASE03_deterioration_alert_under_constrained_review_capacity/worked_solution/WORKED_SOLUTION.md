# Worked solution: Deterioration Alert Under Constrained Review Capacity

## Interpretation

Threshold A minimizes missed cases but produces an unmanageable alert load. Threshold B still exceeds review capacity. Threshold C fits current capacity but misses more cases. The initial pilot should therefore use a restricted high-specificity action zone with structured review of a gray zone, explicit missed-case monitoring, and a decision about whether response capacity must be expanded.

## Decision record

A complete institutional record should document the comparator, assumptions, evidence cut-off, accountable owner, uncertainty, mandatory safeguards, monitoring thresholds, review date, and exit or renewal criteria.
