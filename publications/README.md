# Publications

The `publications/` directory contains the readable and printable V1.0 companion derived from the canonical resources.

The principal publication is available in:

- PDF for stable reading, printing, citation, and archival distribution; and
- Word for accessible editing, teaching preparation, and local adaptation.

The publication summarizes the complete resource architecture but does not replace the editable chapter resources, machine-readable records, or analytical modules in the Canonical Source.
