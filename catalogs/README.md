# Resource Catalogues

The V1.0 catalogue set is aligned with the current five-Part, fifteen-chapter book structure. It contains **146 active companion resources**, including 24 core institutional records, 20 worked examples plus the common case-analysis method, 40 Python analytical modules, 31 principal figures, and 46 principal tables.

The CSV and JSON files are the machine-readable sources for generated website and distribution catalogues. The XLSX files provide reader-friendly spreadsheet views. Stable identifiers should be used in preference to printed page numbers.
