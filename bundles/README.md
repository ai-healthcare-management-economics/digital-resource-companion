# Consolidated working resources

`core_forms/` contains the consolidated forms in editable Word and printable PDF formats. `core_workbooks/` contains the consolidated Excel workbook and `WORKBOOK_GUIDE.md`. These convenience documents are synchronized with the individual resources in `chapters/`.

A Word form preserves narrative justification, review, conditions, and sign-off. The workbook provides structured entries and calculations. Retain both formats when they serve different tasks. The Core Tools Pack is supplied separately as a lightweight release download; no nested ZIP is needed here.
