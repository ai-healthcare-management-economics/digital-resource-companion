# Consolidated Resource Bundles

The `bundles/` directory provides public convenience files generated from the canonical V1.0 resources.

## Core Resource Forms

`core_forms/` contains the 19 core institutional records as a consolidated editable Word document and printable PDF.

## Core Resource Workbooks

`core_workbooks/` contains the 19 records as a consolidated Excel workbook, together with completion guidance.

## Core Tools Pack

`core_tools/` contains `AIHE_Core_Tools_V1.0.zip`, a lightweight package combining the consolidated forms, workbook, completion guidance, licence terms, limited-use notice, and package manifest.

The Core Tools Pack is a convenience subset of the Digital Resource Companion and does not constitute a separate edition. Individual chapter folders remain the authoritative source for resource-specific metadata, schemas, process files, machine-readable records, and analytical material.
