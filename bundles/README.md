# Consolidated Resource Bundles

- `core_forms/` contains the 24 canonical institutional records in one document.
- `core_workbooks/` contains the same core resources in one spreadsheet workbook.
- `core_tools/` contains the optional `AIHE_Core_Tools_V1.0.zip` convenience pack, combining the consolidated forms and workbooks for lightweight distribution.

Individual resource folders remain the canonical source for resource-specific metadata, schemas, process flows, and machine-readable records.

The Core Tools Pack is a convenience subset and does not constitute a separate edition.
