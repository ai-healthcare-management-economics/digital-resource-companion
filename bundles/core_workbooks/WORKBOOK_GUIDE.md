# Workbook Guide

The consolidated workbook and individual resource workbooks support structured institutional analysis. They should be completed as governed local records rather than used as anonymous calculation files.

## Before use

- Record the organization, decision, intervention and version, evidence cut-off, accountable owner, and next review date.
- Preserve the original V1.0 source and create a controlled working copy.
- Replace all illustrative or synthetic content with authorized evidence.
- Mark unknowns explicitly; do not replace missing evidence with a reassuring average value.
- Keep assumptions, observed values, modelled estimates, value judgements, and supplier claims distinguishable.

## Completion

Use the resource index to select only the worksheets required for the decision. Each worksheet identifies its primary chapter, purpose, inputs, expected output, and decision record. Quantitative fields should retain units, source, time period, perspective, and uncertainty.

## Formula and model control

- Do not overwrite formula cells unless a documented local model change is intended.
- Record changed formulas, parameters, named ranges, validation lists, and external links.
- Review calculations after software conversion or import into another spreadsheet application.
- Preserve a read-only baseline and a dated output copy for consequential analyses.

## Data protection

Do not enter identifiable patient information, credentials, private keys, confidential contracts, or restricted institutional information into uncontrolled copies.

## Finalization

End each completed record with a decision, conditions, unresolved uncertainty, safeguards, accountable owners, monitoring thresholds, next review date, transition triggers, and an exit or retirement route.
